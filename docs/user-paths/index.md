# 使用路线

先区分任务是在讨论一个可能的新研究、处理已有 Study，还是已经明确进入伦理准备。路线选择只用于导航，不是研究、治理或发布决定。

| 你的任务 | 从哪里进入 | 不会发生什么 |
| --- | --- | --- |
| 研究想法仍不完整 | [可能的新研究](possible-new-study.md) | 不会建目录、读数据或选方法 |
| 已有 Study 的分析、写作或返修 | [既有 Study、手稿与返修](existing-study-manuscript-revision.md) | 不会误建新 Study |
| 已明确需要伦理准备 | [伦理准备何时可进入](ethics-preparation.md) | 不会自动提交或认定批准 |
