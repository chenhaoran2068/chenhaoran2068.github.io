<header class="guide-header"><p class="guide-kind">research-paper-reading 使用指南</p><h1>受控知识保留</h1><p>此路线适用于希望将指定论文的阅读产出保留在受管本地知识服务中的用户。它从不是默认阅读模式。</p></header>

<section class="guide-section"><div class="guide-summary"><p>使用前需安装兼容的 Framework 和 research-paper-reading，并由用户显式启用受管本地文献库。没有这项配置，阅读仍保持 session_only。</p><div class="release-stamp"><span>相关组件</span><strong>Framework + research-paper-reading</strong></div></div></section>

<section class="guide-section" aria-labelledby="managed-steps"><div class="section-header"><div><p class="section-context">进入条件</p><h2 id="managed-steps">逐项确认来源与保留范围</h2></div></div><div class="guide-step-list"><article><h3>验证兼容组件</h3><p>安装并核对兼容的 Framework 与 research-paper-reading Skill。</p></article><article><h3>显式启用本地服务</h3><p>确认受管本地文献库的管理者、位置和保留边界。</p></article><article><h3>指定一份来源</h3><p>只为一份指定来源确认下载、导入或保留的授权；不能将此确认批量扩展到其他来源。</p></article><article><h3>单独决定后续去向</h3><p>阅读后，才可讨论是否保留阅读档案、知识候选或经验候选；任何 Study handoff 仍需要独立的人类决定。</p></article></div></section>

<section class="guide-section" aria-labelledby="managed-boundary"><div class="section-header"><div><p class="section-context">停止边界</p><h2 id="managed-boundary">不扫描、不批量、不自动提升</h2></div></div><div class="boundary-grid"><div><h3>来源边界</h3><p>服务不会扫描现有文件、批量导入论文或同步云端文献库。</p></div><div><h3>治理边界</h3><p>不会自动贴标签、创建知识卡、建立经验或提升正式规则。</p></div></div></section>
