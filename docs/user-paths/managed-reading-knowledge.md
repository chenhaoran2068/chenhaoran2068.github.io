# Managed reading and knowledge service

This route is for users who want to retain paper-reading outputs in a managed local knowledge service. It is never the default route.

1. Install and verify the compatible Framework and `research-paper-reading` Skill.
2. Explicitly enable the managed local reference library and confirm its manager and retention boundary.
3. Name one source and authorize the permitted download, import, or retention action.
4. Read with the Skill, then decide whether to retain a dossier, knowledge candidate, or experience candidate.
5. A handoff to one named Study requires a separate explicit human decision and is metadata-only.

This route does not scan existing files, batch-import papers, synchronize a cloud library, auto-tag content, create knowledge cards automatically, or promote rules automatically.
