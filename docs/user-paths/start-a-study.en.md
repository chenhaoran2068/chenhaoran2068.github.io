<header class="guide-header"><p class="guide-kind">Governed Research Workflow</p><h1>I want to do a research Study</h1><p>Start with a research idea, an existing project, or a topic that is still unclear. This page helps you enter the research route; the System page remains authoritative for the full stages, Study layout, and material locations.</p></header>

<section class="guide-section" aria-labelledby="study-setup-title"><div class="section-header"><div><p class="section-context">Prepare the foundation first</p><h2 id="study-setup-title">What is needed before starting?</h2></div></div><div class="guide-step-list"><article><h3>A workspace Framework</h3><p>Install <a href="https://github.com/chenhaoran2068/governed-research-workspace-framework/releases/tag/v0.4.0">Governed Research Workspace Framework v0.4.0</a> to create the workspace structure and place Systems, Skills, Studies, Knowledge, and other materials.</p></article><article><h3>A Research System</h3><p>Install <a href="https://github.com/chenhaoran2068/governed-research-workflow/releases/tag/v1.18.0">Governed Research Workflow v1.18.0</a> to move from an idea and design through protocol, analysis, writing, submission, and archive.</p></article><article><h3>An AI environment that can load components</h3><p>The AI you use must be able to read the installed Framework and System. The exact setup depends on the tool. <code>research-paper-reading v0.3.0</code>, <code>research-ethics v1.1.1</code>, and <code>governed-engineering v0.1.1</code> are optional components to add only when the work reaches those tasks.</p></article></div></section>

<section class="guide-section" aria-labelledby="study-setup-prompt-title"><div class="section-header"><div><p class="section-context">Use this for first-time setup</p><h2 id="study-setup-prompt-title">Copy this prompt into the AI</h2></div></div><p>Replace the bracketed workspace name and location. The AI first configures and verifies the foundation, then enters new-Study navigation. The topic and data may still be unknown.</p><pre class="study-setup-prompt"><code>I want to configure a research collaboration workspace and begin a new Study after setup has been verified.&#10;&#10;Workspace name: [for example, MyResearch]&#10;Candidate workspace location: [enter an absolute path]&#10;Collaboration mode: human-AI interactive mode&#10;&#10;I authorize you to:&#10;1. Check whether Governed Research Workspace Framework v0.4.0 and Governed Research Workflow v1.18.0 are installed in the current environment.&#10;2. If either is missing, follow the formal instructions for its exact public Release to download, configure, and verify it at the candidate location. Do not modify another existing workspace.&#10;3. Create the workspace structure and report the actual installation locations, versions, test results, and remaining conditions.&#10;4. After setup passes verification, enter new-Study navigation as if I had said “I want to start a new research Study.” If the topic or data is not yet defined, ask for the missing information first.&#10;&#10;Before I accept a proposed route, do not create a Study, read or copy real data, or infer ethics, data-access, or registration status.</code></pre></section>

<section class="guide-section" aria-labelledby="study-start-title"><div class="section-header"><div><p class="section-context">State where you are now</p><h2 id="study-start-title">Start this way in the chat box</h2></div></div><div class="guide-step-list"><article><h3>Start a new Study</h3><p>Open a new conversation and send “I want to start a new research Study.” The topic, data, and method do not need to be complete; begin with what concerns you.</p></article><article><h3>Continue an existing Study</h3><p>Provide the Study name or exact root directory, then state the current task, such as revising a protocol, reviewing results, writing a manuscript, or responding to reviewers.</p></article><article><h3>Discuss an idea first</h3><p>State the question or idea directly. The AI first distinguishes a possible new Study, an existing project, or discussion only; it does not thereby create a Study, read data, or choose a design for you.</p></article></div></section>

<section class="guide-section" aria-labelledby="study-mode-title"><div class="section-header"><div><p class="section-context">Then choose how to proceed</p><h2 id="study-mode-title">Choose the collaboration mode</h2></div></div><div class="boundary-grid"><div><h3>Human-AI interactive mode</h3><p>Send “human-AI interactive mode” in the chat box. You and the AI confirm, advance, and review each stage together. This is the current default.</p></div><div><h3>AI autonomous mode</h3><p>Send “AI autonomous mode” in the chat box. It applies only to a bounded portion of work with stated scope, inputs, actions, outputs, stop conditions, and human gates; it does not hand an entire Study to the AI.</p></div></div></section>

<section class="guide-section" aria-labelledby="study-route-title"><div class="section-header"><div><p class="section-context">Enter the full route</p><h2 id="study-route-title">What happens afterwards?</h2></div></div><div class="guide-summary"><p>Research question, design, protocol, scientific review, ethics and filing, key check, full analysis, manuscript, submission, revision, and archive are all staged in the <a href="../../systems/governed-research-workflow/">Governed Research Workflow</a>. At stage 05, invoke <code>research-ethics</code> by name when ethics or registration materials are needed.</p></div></section>

<p class="guide-boundary-note"><strong>Before route approval:</strong> Do not create a real Study, read or copy real data, or infer ethics, registration, or data-access status.</p>
