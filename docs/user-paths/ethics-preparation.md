<header class="guide-header"><p class="guide-kind">research-ethics 使用指南</p><h1>伦理准备</h1><p>仅当用户明确请求伦理或登记准备，并能确认适用路线、具名 Study、材料模式、允许读取范围和目标交付物时，才可考虑进入 research-ethics。</p></header>

<section class="guide-section"><div class="guide-summary"><p>缺少任何关键前提时，应停在缺口或确认阶段。该 Skill 协助组织材料，不会替人类确认伦理、数据访问或登记状态。</p><div class="release-stamp"><span>相关组件</span><strong>research-ethics</strong></div></div></section>

<section class="guide-section" aria-labelledby="ethics-steps"><div class="section-header"><div><p class="section-context">进入前核对</p><h2 id="ethics-steps">五项明确输入</h2></div></div><div class="guide-step-list"><article><h3>明确请求</h3><p>用户明确说明要进行伦理或登记准备，而非普通研究讨论。</p></article><article><h3>确认路线</h3><p>确认属于当前 Skill 支持的中国大陆观察性研究范围；其他路线必须转入专门模块。</p></article><article><h3>指定 Study</h3><p>给出具名 Study 根目录；没有明确对象时不能假定材料归属。</p></article><article><h3>限定材料模式</h3><p>说明本次允许读取的范围与模式，不能把一次允许扩展为持续访问。</p></article><article><h3>明确交付物</h3><p>说明希望生成或检查的内容，例如计划书骨架、缺口清单或平台填写稿。</p></article></div></section>

<section class="guide-section" aria-labelledby="ethics-guide-boundary"><div class="section-header"><div><p class="section-context">停止边界</p><h2 id="ethics-guide-boundary">准备不是提交</h2></div></div><div class="boundary-grid"><div><h3>不推断批准</h3><p>系统不会把草稿或核对结果写成伦理批准、豁免或注册完成。</p></div><div><h3>不连接平台</h3><p>不上传、不提交、不调用任何外部伦理或登记平台。</p></div></div></section>
