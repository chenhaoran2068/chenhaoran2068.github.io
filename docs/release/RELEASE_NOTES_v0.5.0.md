# Chenhaoran Portal v0.5.0

## Updated

- Adds complete Chinese, English, and Japanese portal routes for the current
  public pages.
- Adds a visible same-page language selector: `中文 EN 日本語`. It does not use
  browser-language detection or automatic redirects.
- Adds explicit translation coverage checks and disables fallback to Chinese
  when a localized page is missing.
- Refines the public portal's navigation, component directories, visual
  system, setup guidance, and research-workflow explanation.
- Updates GitHub Actions checkout and Python setup actions to their Node 24
  runtime versions, removing the observed Node 20 deprecation warnings.

## Boundaries

- Formal component names, version identifiers, paths, code identifiers, and
  exact Release links remain unchanged.
- Historical Release Notes and the formal documents in component repositories
  are not translated by this portal release.
- This release does not modify a Framework, System, Skill, local runtime,
  Study, data source, account, or external integration.
