# Chenhaoran Portal v0.4.1

## Scope

- Adds a public component catalogue for reviewed, first-party repositories.
- Adds Governed Engineering v0.1.1 as a public Skill package with five bounded engineering Skills.
- Separates current components, method support, historical related projects, and independent projects.
- Reorganizes the portal around component categories, task guides, integrations, and version/governance pages.
- Refreshes the visual system as a restrained, Chinese-first navigation directory while retaining formal component names.
- Adds an external integrations page with the reviewed optional Zotero boundary.
- Keeps the home page limited to current public research collaboration components.
- Updates the Governed Research Workflow record to its released v1.13.0 lifecycle-decision clarification.

## Boundaries

- Does not add an online editor, CMS, automatic synchronization, or user account system.
- Does not list private pilots, unreviewed repositories, or the pending `literature-review` Skill.
- Does not change any Framework, System, Skill, runtime, or external tool.
