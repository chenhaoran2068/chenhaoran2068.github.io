# Research Collaboration Portal v0.5.5

## Updated

- Updates all current Governed Research Workflow references to the released
  `v1.18.0` package.
- Adds aligned Chinese, English, and Japanese explanations of the Study status
  snapshot and the paper repository preparation standard.
- Updates the homepage setup prompt, getting-started route, System overview,
  and release table to use the same current System version.

## Boundaries

- This release changes public portal documentation only.
- It does not create or publish a paper repository, modify a Study, infer a
  Study status, access data, or grant research or release authority.
