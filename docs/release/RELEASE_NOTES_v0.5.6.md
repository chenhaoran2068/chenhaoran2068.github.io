# Research Collaboration Portal v0.5.6

## Updated

- Updates current Governed Research Workflow references to public release
  `v1.18.1`.
- Adds aligned Chinese, English, and Japanese explanations of repository naming
  and the controlled move from a Study-owned clean candidate to
  `Github/<repository-name>/`.
- Keeps full research identity in the README and Study summary instead of
  treating every study as a PICOS-shaped repository name.

## Boundaries

- This release changes public portal documentation only.
- It does not inspect or modify a real Study, create a repository, copy files to
  `Github/`, publish research materials, or grant release authority.
