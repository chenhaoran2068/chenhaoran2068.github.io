<section class="guide-section" id="problems"><div class="section-header"><div><p class="section-context">現象から開く</p><h2>よくある問題</h2></div><p>意味、原因、担当者、対応、禁止する回避策を示します。</p></div><div class="troubleshooting-details">
<details><summary>Tailscale 端末がオフラインまたは承認待ち</summary><div><p><strong>意味：</strong>端末またはサーバーが承認済み tailnet で通信できません。</p><p><strong>原因：</strong>電源、未ログイン、別アカウント、期限切れ、端末承認待ち。</p><p><strong>担当：</strong>研究者は端末、管理者はサーバーと承認を確認。</p><p><strong>対応：</strong><code>tailscale status</code> とログイン・承認状態を確認。</p><p><strong>禁止：</strong>公開 IP や他人の端末 ID を使う。</p></div></details>
<details><summary>MagicDNS が解決できない</summary><div><p><strong>意味：</strong>MagicDNS 名を tailnet 内アドレスへ変換できません。</p><p><strong>原因：</strong>綴り、MagicDNS 無効、DNS 状態、別 tailnet。</p><p><strong>担当：</strong>研究者は受領名、管理者は MagicDNS を確認。</p><p><strong>対応：</strong><code>tailscale ping &lt;server-magicdns-name&gt;</code> を使用。</p><p><strong>禁止：</strong>証明書 SAN にない IP へ置換。</p></div></details>
<details><summary>connection timeout</summary><div><p><strong>意味：</strong>時間内に PostgreSQL セッションを開始できません。</p><p><strong>原因：</strong>サーバーまたは PostgreSQL の停止、Tailscale 経路の不通、network policy による拒否。</p><p><strong>担当：</strong>研究者は端末の接続状態、管理者はサーバーと network policy を確認します。</p><p><strong>対応：</strong>Tailscale、MagicDNS、サーバー状態の順に確認します。</p><p><strong>禁止：</strong>timeout の無制限な延長や公開 port の開放。</p></div></details>
<details><summary>ポート設定が違う</summary><div><p><strong>意味：</strong>ホスト名は解決できますが、管理者が渡した PostgreSQL port とは別の port に接続しています。</p><p><strong>原因：</strong>既定値の転用、古い接続 profile、入力ミス。</p><p><strong>担当：</strong>研究者は接続設定、管理者は現在の port を確認します。</p><p><strong>対応：</strong>DBeaver または psql の値を管理者の引き継ぎ内容と照合し、その項目だけを修正します。</p><p><strong>禁止：</strong>周辺 port の scan や推測による置き換え。</p></div></details>
<details><summary>certificate verify failed</summary><div><p><strong>意味：</strong>指定したルート CA でサーバー証明書を検証できません。</p><p><strong>原因：</strong>CA 誤り、破損、期限切れ、別サービスへの接続。</p><p><strong>担当：</strong>研究者は CA、管理者は証明書チェーンと期限を確認。</p><p><strong>対応：</strong>CA の入手元、指紋、期限、接続先を確認。</p><p><strong>禁止：</strong>検証を無効にする、<code>require</code> へ変更。</p></div></details>
<details><summary>ホスト名と証明書 SAN が一致しない</summary><div><p><strong>意味：</strong>Host が証明書で許可された名前ではありません。</p><p><strong>原因：</strong>短い名前、IP、古い MagicDNS 名、SAN 不足。</p><p><strong>担当：</strong>研究者は正式名、管理者は必要時に証明書を再発行。</p><p><strong>対応：</strong><code>verify-full</code> を維持し、Host と SAN を一致。</p><p><strong>禁止：</strong>ホスト名検証をスキップ。</p></div></details>
<details><summary>password authentication failed</summary><div><p><strong>意味：</strong>アカウント認証が受理されません。</p><p><strong>原因：</strong>ユーザー名・パスワード、期限・失効、DB 誤り、SCRAM 非対応クライアント。</p><p><strong>担当：</strong>研究者は再入力、管理者はアカウント状態を確認。</p><p><strong>対応：</strong>ユーザー名、DB、期限、クライアント版を確認。</p><p><strong>禁止：</strong>パスワードをチケット、コマンド、ファイル、画像で送る。</p></div></details>
<details><summary>schema は見えるが表を検索できない</summary><div><p><strong>意味：</strong>表示されるだけでは schema USAGE と表 SELECT は保証されません。</p><p><strong>原因：</strong>一方の権限不足、新しい表、allowlist 外。</p><p><strong>担当：</strong>管理者が承認範囲を確認。研究者は自己昇格しません。</p><p><strong>対応：</strong><code>has_schema_privilege</code> と <code>has_table_privilege</code> を実行。</p><p><strong>禁止：</strong>governance、registry、未承認出典の一括権限。</p></div></details>
<details><summary>DBeaver ドライバーがない</summary><div><p><strong>意味：</strong>PostgreSQL JDBC ドライバーを利用できません。</p><p><strong>原因：</strong>初回利用、proxy・ネットワーク制限、cache 破損。</p><p><strong>担当：</strong>クライアント支援または研究者。</p><p><strong>対応：</strong>DBeaver Driver Manager と公式配布元を使用。</p><p><strong>禁止：</strong>不明サイトからのダウンロード。</p></div></details>
<details><summary>サーバーまたは PostgreSQL が停止</summary><div><p><strong>意味：</strong>応答する DB サービスがありません。</p><p><strong>原因：</strong>保守、障害、停電。</p><p><strong>担当：</strong>サーバー管理者。</p><p><strong>対応：</strong>保守時間と復旧予定を確認。</p><p><strong>禁止：</strong>クライアント証明書やパスワードを繰り返し変更。</p></div></details>
<details><summary>アクセス期限切れ、停止、失効</summary><div><p><strong>意味：</strong>以前有効だった端末またはアカウントに現在の許可がありません。</p><p><strong>原因：</strong>期限、端末紛失、担当・プロジェクト変更、再確認未完了。</p><p><strong>担当：</strong>データ責任者と管理者。</p><p><strong>対応：</strong>現在の範囲で再申請または再確認。</p><p><strong>禁止：</strong>他人の有効なアカウントを使う。</p></div></details>

<section class="guide-section" id="permissions"><div class="section-header"><div><p class="section-context">一つのスイッチではない</p><h2>読み取り専用が各層で成立すること</h2></div></div><div class="permission-layers"><article><span>01</span><div><h3>接続</h3><p>Tailscale、TLS、CONNECT、認証が成功。</p></div></article><article><span>02</span><div><h3>schema 利用</h3><p>allowlist の schema だけに USAGE。</p></div></article><article><span>03</span><div><h3>承認済み表の検索</h3><p>明示した表だけに SELECT。新しい schema は自動承認されません。</p></div></article><article><span>04</span><div><h3>書込・昇格不可</h3><p>CREATE、INSERT、UPDATE、DELETE、TRUNCATE、superuser、DB・role 作成、replication は不可。</p></div></article></div></section>
<section class="guide-section" id="security"><div class="section-header"><div><p class="section-context">維持する条件</p><h2>安全要件</h2></div></div><div class="security-columns"><div><h3>ネットワークと ID</h3><ul><li>PostgreSQL を公開インターネットへ直接公開しない。</li><li>一人一アカウント。</li><li>端末紛失時は Tailscale と DB アカウントを両方失効。</li></ul></div><div><h3>パスワードと証明書</h3><ul><li>パスワードを script、Web、画像、Git に残さない。</li><li>ルート CA 証明書は配布可、秘密鍵は不可。</li><li>サーバー秘密鍵はサーバー内のみ。</li></ul></div><div><h3>最小範囲</h3><ul><li>必要な schema と表だけを承認。</li><li>governance、registry、未承認出典にはアクセスしない。</li><li>新しい schema は明示的に審査。</li></ul></div></div></section>
<section class="guide-section" id="operations"><div class="section-header"><div><p class="section-context">日常利用</p><h2>クイックチェック</h2></div></div><ul class="quick-check"><li>端末とサーバーが承認済み tailnet でオンライン。</li><li>Host は証明書 SAN の MagicDNS 名。</li><li>TLS は <code>verify-full</code>。</li><li>個人アカウントを使用し、パスワードを公開物に保存していない。</li><li>承認済み schema と表だけを検索。</li><li>期限、allowlist、証明書期限を定期確認。</li><li>サーバーの新しいコミット済みデータは新しい検索に現れ、DB コピーは不要。</li><li>DBeaver は GUI が必要なクライアントだけに導入。</li></ul><h3 class="sources-heading">公式資料</h3><ul class="official-sources"><li><a href="https://www.postgresql.org/docs/current/libpq-connect.html">PostgreSQL: connection parameters</a></li><li><a href="https://www.postgresql.org/docs/current/libpq-ssl.html">PostgreSQL: SSL support</a></li><li><a href="https://www.postgresql.org/docs/current/auth-password.html">PostgreSQL: password authentication</a></li><li><a href="https://tailscale.com/kb/1081/magicdns">Tailscale: MagicDNS</a></li><li><a href="https://dbeaver.com/docs/dbeaver/SSL-Configuration/">DBeaver: SSL configuration</a></li></ul></section>
