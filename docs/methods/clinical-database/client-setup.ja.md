<header class="guide-header"><p class="guide-kind">Clinical Database · クライアント</p><h1>リモート読み取り専用クライアントを設定・検証する</h1><p>アクセスが承認され、管理者から接続資料を受け取った後に使います。Windows と macOS は Tailscale のプライベートネットワークから同じ PostgreSQL を検索し、DB コピーは保持しません。</p></header>
<nav class="database-guide-nav"><a href="#handoff-package">引き継ぎ確認</a><a href="#architecture">接続経路</a><a href="#client-setup">インストール</a><a href="#dbeaver">DBeaver</a><a href="#psql">psql</a><a href="#validation">検証</a><a href="../troubleshooting/">問題</a></nav>
<section class="guide-section" id="handoff-package"><div class="section-header"><div><p class="section-context">開始条件</p><h2>管理者からの接続資料を確認する</h2></div><p>不足があれば<a href="../remote-access/">アクセス申請</a>に戻ります。値を推測したり検証を弱めたりしません。</p></div><ul class="database-checklist"><li>MagicDNS 名 <code>&lt;server-magicdns-name&gt;</code>。</li><li>PostgreSQL ポート <code>&lt;postgresql-port&gt;</code>。</li><li>データベース名 <code>&lt;database-name&gt;</code>。</li><li>個人用 <code>&lt;read-only-user&gt;</code>。パスワードは別経路で受領。</li><li>許可済み schema と検証用の許可済み表。</li><li>配布可能な <code>root-ca.crt</code>。秘密鍵ではありません。</li><li>サーバー証明書 SAN に MagicDNS 名があること。</li></ul><div class="db-notice db-notice-warning"><strong>秘密鍵を受け取らない</strong><p>ルート CA 公開証明書は配布できます。CA 秘密鍵とサーバー秘密鍵はサーバー側に残します。</p></div></section>
<section class="guide-section" id="architecture"><div class="section-header"><div><p class="section-context">接続経路</p><h2>クエリがデータベースに届くまで</h2></div><p>Tailscale が到達性を制御し、PostgreSQL TLS がサーバーの本人性を検証して通信を暗号化します。</p></div><div class="database-access-flow"><article><span>01</span><div><h3>Windows または macOS</h3><p>DBeaver または psql とルート CA 公開証明書。</p></div></article><div class="database-flow-arrow">↓</div><article><span>02</span><div><h3>Tailscale プライベートネットワーク</h3><p>端末とサーバーが承認済み tailnet に参加します。同じ Wi-Fi は不要です。</p></div></article><div class="database-flow-arrow">↓</div><article><span>03</span><div><h3>MagicDNS と TLS <code>verify-full</code></h3><p>接続名と SAN を一致させ、証明書チェーンとホスト名を検証します。</p></div></article><div class="database-flow-arrow">↓</div><article><span>04</span><div><h3>SCRAM と個人用読み取り専用アカウント</h3><p>許可された schema と表だけを検索します。</p></div></article></div><div class="db-notice"><strong>サーバーの最新コミット済みデータが見えます</strong><p>クライアントはサーバーを直接検索します。サーバー、PostgreSQL、Tailscale が停止すると利用できません。</p></div></section>

<section class="guide-section" id="dbeaver"><div class="section-header"><div><p class="section-context">GUI</p><h2>DBeaver の設定</h2></div></div><div class="database-table-wrap"><table class="database-config-table"><thead><tr><th>項目</th><th>値</th><th>注意</th></tr></thead><tbody><tr><td>Host</td><td><code>&lt;server-magicdns-name&gt;</code></td><td>SAN と一致。<code>https://</code> は不要。</td></tr><tr><td>Port</td><td><code>&lt;postgresql-port&gt;</code></td><td>管理者の値。</td></tr><tr><td>Database</td><td><code>&lt;database-name&gt;</code></td><td>承認済み DB。</td></tr><tr><td>Username</td><td><code>&lt;read-only-user&gt;</code></td><td>個人アカウント。</td></tr><tr><td>Password</td><td>接続時に入力</td><td>Web、スクリプト、画像、Git に残さない。</td></tr><tr><td>SSL mode</td><td><code>verify-full</code></td><td>CA とホスト名を検証。</td></tr><tr><td>Root certificate</td><td><code>&lt;path-to-root-ca.crt&gt;</code></td><td>受領したルート CA。</td></tr><tr><td>Client certificate / key</td><td>空欄</td><td>将来 mTLS を使う時だけ。</td></tr><tr><td>Skip host name validation</td><td>オフ</td><td>ホスト名検証を回避しない。</td></tr></tbody></table></div><div class="db-notice db-notice-warning"><strong><code>verify-full</code> を <code>require</code> に変えない</strong><p>CA、MagicDNS、SAN を修正し、本人性検証を無効にしません。</p></div></section>
<section class="guide-section" id="psql"><div class="section-header"><div><p class="section-context">CLI</p><h2>psql を使う</h2></div><p>パスワードは対話入力し、保存しません。</p></div><div class="command-pair"><article><h3>Windows PowerShell</h3><p><a href="https://www.postgresql.org/download/windows/">PostgreSQL 公式 Windows ページ</a>から psql を取得します。</p><pre data-copy><code>$env:PGHOST = '&lt;server-magicdns-name&gt;'&#10;$env:PGPORT = '&lt;postgresql-port&gt;'&#10;$env:PGDATABASE = '&lt;database-name&gt;'&#10;$env:PGUSER = '&lt;read-only-user&gt;'&#10;$env:PGSSLMODE = 'verify-full'&#10;$env:PGSSLROOTCERT = (Join-Path $HOME 'DatabaseAccess\root-ca.crt')&#10;$env:PGCONNECT_TIMEOUT = '10'&#10;$env:PGREQUIREAUTH = 'scram-sha-256'&#10;$env:PGCHANNELBINDING = 'require'&#10;psql -W</code></pre></article><article><h3>macOS shell</h3><p><a href="https://www.postgresql.org/download/macosx/">PostgreSQL 公式 macOS ページ</a>を参照します。</p><pre data-copy><code>brew install libpq&#10;export PGHOST='&lt;server-magicdns-name&gt;'&#10;export PGPORT='&lt;postgresql-port&gt;'&#10;export PGDATABASE='&lt;database-name&gt;'&#10;export PGUSER='&lt;read-only-user&gt;'&#10;export PGSSLMODE='verify-full'&#10;export PGSSLROOTCERT="$HOME/Library/Application Support/DatabaseAccess/root-ca.crt"&#10;export PGCONNECT_TIMEOUT='10'&#10;export PGREQUIREAUTH='scram-sha-256'&#10;export PGCHANNELBINDING='require'&#10;"$(brew --prefix libpq)/bin/psql" -W</code></pre></article></div></section>
<section class="guide-section" id="validation"><div class="section-header"><div><p class="section-context">検索前</p><h2>患者値を読まない検証</h2></div></div><h3>セッションと TLS</h3><pre data-copy><code>SELECT current_database(), current_user,&#10;       current_setting('transaction_read_only') AS transaction_read_only;&#10;SELECT ssl, version, cipher FROM pg_stat_ssl WHERE pid = pg_backend_pid();</code></pre><h3>schema と表権限</h3><pre data-copy><code>SELECT has_schema_privilege(current_user, '&lt;approved-schema&gt;', 'USAGE') AS schema_usage,&#10;       has_schema_privilege(current_user, '&lt;approved-schema&gt;', 'CREATE') AS schema_create;&#10;SELECT has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'SELECT') AS can_select,&#10;       has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'INSERT') AS can_insert,&#10;       has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'UPDATE') AS can_update,&#10;       has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'DELETE') AS can_delete,&#10;       has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'TRUNCATE') AS can_truncate;</code></pre><h3>失敗する書込確認</h3><div class="db-notice db-notice-warning"><strong>事前承認したオブジェクト名だけを使う</strong><p>存在しないことを確認し、<code>BEGIN READ ONLY</code> で実行します。TEMP 表は使いません。</p></div><pre data-copy><code>SELECT to_regclass('&lt;approved-schema&gt;.&lt;approved-write-probe&gt;') IS NULL AS safe_to_test;&#10;BEGIN READ ONLY;&#10;CREATE TABLE &lt;approved-schema&gt;.&lt;approved-write-probe&gt; (probe_id integer);&#10;ROLLBACK;&#10;SELECT to_regclass('&lt;approved-schema&gt;.&lt;approved-write-probe&gt;') IS NULL AS probe_absent;</code></pre><div class="success-criteria"><h3>接続成功の判定</h3><ul><li>MagicDNS が使え、<code>verify-full</code> が有効。</li><li>SCRAM と、対応時は channel binding が成功。</li><li><code>current_database()</code>、<code>current_user</code>、読み取り専用状態が正しい。</li><li><code>pg_stat_ssl</code> が SSL を示す。</li><li>承認済み schema の USAGE と表 SELECT だけが true。</li><li>CREATE、INSERT、UPDATE、DELETE、TRUNCATE は false。</li><li>書込が失敗し、<code>probe_absent</code> が true。</li></ul></div></section>
