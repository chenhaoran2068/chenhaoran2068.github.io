<header class="guide-header"><p class="guide-kind">Clinical Database · client</p><h1>Configure and validate a remote read-only client</h1><p>Use this guide after access is approved and the administrator has delivered the connection package. Windows and macOS reach the same PostgreSQL service over a private Tailscale network; no client database copy is maintained.</p></header>

<section class="guide-section" id="handoff-package"><div class="section-header"><div><p class="section-context">Start condition</p><h2>Check the administrator handoff</h2></div><p>If an item is missing, return to the <a href="../remote-access/">access request</a>. Do not guess or weaken validation.</p></div><ul class="database-checklist"><li>MagicDNS host <code>&lt;server-magicdns-name&gt;</code>.</li><li>PostgreSQL port <code>&lt;postgresql-port&gt;</code>.</li><li>Database <code>&lt;database-name&gt;</code>.</li><li>Your individual <code>&lt;read-only-user&gt;</code>; receive its password separately.</li><li>The approved schema and one approved validation table.</li><li>The distributable <code>root-ca.crt</code>, never a private key.</li><li>Confirmation that the server certificate SAN contains the MagicDNS host.</li></ul><div class="db-notice db-notice-warning"><strong>Do not accept a private key</strong><p>The root CA certificate may be distributed. The root CA private key and server private key remain server-side.</p></div></section>
<section class="guide-section" id="architecture"><div class="section-header"><div><p class="section-context">Connection path</p><h2>How a query reaches the database</h2></div><p>Tailscale controls reachability; PostgreSQL TLS verifies server identity and encrypts the session.</p></div><div class="database-access-flow"><article><span>01</span><div><h3>Windows or macOS</h3><p>DBeaver or psql with the public root CA certificate.</p></div></article><div class="database-flow-arrow">↓</div><article><span>02</span><div><h3>Private Tailscale network</h3><p>Client and server share an approved tailnet; they need not share Wi-Fi.</p></div></article><div class="database-flow-arrow">↓</div><article><span>03</span><div><h3>MagicDNS and TLS <code>verify-full</code></h3><p>The connection name matches the server certificate SAN and the chain is verified.</p></div></article><div class="database-flow-arrow">↓</div><article><span>04</span><div><h3>SCRAM and an individual read-only account</h3><p>Only approved schemas and tables can be queried.</p></div></article></div><div class="db-notice"><strong>New committed data is visible on the server</strong><p>The client queries the server directly. If the server, PostgreSQL, or Tailscale is offline, remote access is unavailable.</p></div></section>
<section class="guide-section" id="client-setup"><div class="section-header"><div><p class="section-context">By operating system</p><h2>Install Tailscale and a query client</h2></div><p>Keep the certificate in a personal controlled directory, not Git, shared storage, or screenshots.</p></div><div class="os-tabs" data-os-tabs><div class="os-tab-list" role="tablist"><button type="button" role="tab" aria-selected="true" aria-controls="windows-panel" id="windows-tab" data-tab-target="windows-panel">Windows</button><button type="button" role="tab" aria-selected="false" aria-controls="macos-panel" id="macos-tab" data-tab-target="macos-panel">macOS</button></div><div class="os-tab-panels"><section id="windows-panel" role="tabpanel" aria-labelledby="windows-tab" data-tab-panel><ol class="platform-steps"><li><h3>Install and sign in to Tailscale</h3><p>Follow the <a href="https://tailscale.com/docs/install/windows">official Windows installation guide</a> and join the approved tailnet.</p></li><li><h3>Check the device and server</h3><pre data-copy><code>tailscale status&#10;tailscale ip -4&#10;tailscale ping &lt;server-magicdns-name&gt;</code></pre></li><li><h3>Install DBeaver Community</h3><p>Use the <a href="https://dbeaver.io/download/">official download</a>. Let DBeaver's driver manager fetch the PostgreSQL driver.</p></li><li><h3>Store the root CA</h3><p>For example, <code>$HOME\DatabaseAccess\root-ca.crt</code>. Use the file picker or <code>Join-Path</code>.</p></li></ol></section><section id="macos-panel" role="tabpanel" aria-labelledby="macos-tab" data-tab-panel hidden><ol class="platform-steps"><li><h3>Install and sign in to Tailscale</h3><p>Follow the <a href="https://tailscale.com/docs/install/mac">official macOS installation guide</a>.</p></li><li><h3>Check the device and server</h3><pre data-copy><code>tailscale status&#10;tailscale ip -4&#10;tailscale ping &lt;server-magicdns-name&gt;</code></pre></li><li><h3>Install DBeaver Community</h3><p>Use the <a href="https://dbeaver.io/download/">official macOS download</a>.</p></li><li><h3>Store the root CA</h3><pre data-copy><code>mkdir -p "$HOME/Library/Application Support/DatabaseAccess"&#10;chmod 700 "$HOME/Library/Application Support/DatabaseAccess"&#10;chmod 600 "$HOME/Library/Application Support/DatabaseAccess/root-ca.crt"</code></pre><p>Select the CA file, not a Keychain client identity. This setup does not use mTLS.</p></li></ol></section></div></div></section>
<section class="guide-section" id="dbeaver"><div class="section-header"><div><p class="section-context">GUI client</p><h2>DBeaver configuration</h2></div></div><div class="database-table-wrap"><table class="database-config-table"><thead><tr><th>Field</th><th>Value</th><th>Note</th></tr></thead><tbody><tr><td>Host</td><td><code>&lt;server-magicdns-name&gt;</code></td><td>Must match the SAN; omit <code>https://</code>.</td></tr><tr><td>Port</td><td><code>&lt;postgresql-port&gt;</code></td><td>Use the delivered value.</td></tr><tr><td>Database</td><td><code>&lt;database-name&gt;</code></td><td>Approved database only.</td></tr><tr><td>Username</td><td><code>&lt;read-only-user&gt;</code></td><td>Your individual account.</td></tr><tr><td>Password</td><td>Enter interactively</td><td>Never place it in a page, script, screenshot, or Git.</td></tr><tr><td>SSL mode</td><td><code>verify-full</code></td><td>Verify CA and hostname.</td></tr><tr><td>Root certificate</td><td><code>&lt;path-to-root-ca.crt&gt;</code></td><td>The delivered root CA.</td></tr><tr><td>Client certificate / key</td><td>Blank</td><td>Unless mTLS is introduced later.</td></tr><tr><td>Skip host name validation</td><td>Off</td><td>Do not bypass hostname verification.</td></tr></tbody></table></div><div class="db-notice db-notice-warning"><strong>Do not change <code>verify-full</code> to <code>require</code></strong><p>Repair the CA, MagicDNS name, or SAN rather than bypassing identity verification.</p></div></section>
<section class="guide-section" id="psql"><div class="section-header"><div><p class="section-context">CLI client</p><h2>Use psql</h2></div><p>psql prompts for the password; the examples do not store it.</p></div><div class="command-pair"><article><h3>Windows PowerShell</h3><p>Get psql from the <a href="https://www.postgresql.org/download/windows/">official Windows download</a>.</p><pre data-copy><code>$env:PGHOST = '&lt;server-magicdns-name&gt;'&#10;$env:PGPORT = '&lt;postgresql-port&gt;'&#10;$env:PGDATABASE = '&lt;database-name&gt;'&#10;$env:PGUSER = '&lt;read-only-user&gt;'&#10;$env:PGSSLMODE = 'verify-full'&#10;$env:PGSSLROOTCERT = (Join-Path $HOME 'DatabaseAccess\root-ca.crt')&#10;$env:PGCONNECT_TIMEOUT = '10'&#10;$env:PGREQUIREAUTH = 'scram-sha-256'&#10;$env:PGCHANNELBINDING = 'require'&#10;psql -W</code></pre></article><article><h3>macOS shell</h3><p>See the <a href="https://www.postgresql.org/download/macosx/">official macOS page</a>.</p><pre data-copy><code>brew install libpq&#10;export PGHOST='&lt;server-magicdns-name&gt;'&#10;export PGPORT='&lt;postgresql-port&gt;'&#10;export PGDATABASE='&lt;database-name&gt;'&#10;export PGUSER='&lt;read-only-user&gt;'&#10;export PGSSLMODE='verify-full'&#10;export PGSSLROOTCERT="$HOME/Library/Application Support/DatabaseAccess/root-ca.crt"&#10;export PGCONNECT_TIMEOUT='10'&#10;export PGREQUIREAUTH='scram-sha-256'&#10;export PGCHANNELBINDING='require'&#10;"$(brew --prefix libpq)/bin/psql" -W</code></pre></article></div></section>
<section class="guide-section" id="validation"><div class="section-header"><div><p class="section-context">Before querying</p><h2>Validation without patient values</h2></div></div><h3>Session and TLS</h3><pre data-copy><code>SELECT current_database(), current_user,&#10;       current_setting('transaction_read_only') AS transaction_read_only;&#10;SELECT ssl, version, cipher FROM pg_stat_ssl WHERE pid = pg_backend_pid();</code></pre><h3>Schema and table privileges</h3><pre data-copy><code>SELECT has_schema_privilege(current_user, '&lt;approved-schema&gt;', 'USAGE') AS schema_usage,&#10;       has_schema_privilege(current_user, '&lt;approved-schema&gt;', 'CREATE') AS schema_create;&#10;SELECT has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'SELECT') AS can_select,&#10;       has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'INSERT') AS can_insert,&#10;       has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'UPDATE') AS can_update,&#10;       has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'DELETE') AS can_delete,&#10;       has_table_privilege(current_user, '&lt;approved-schema&gt;.&lt;approved-table&gt;', 'TRUNCATE') AS can_truncate;</code></pre><h3>Expected write failure</h3><div class="db-notice db-notice-warning"><strong>Use only a pre-approved object name</strong><p>Confirm absence first and use <code>BEGIN READ ONLY</code>. Do not use a TEMP table.</p></div><pre data-copy><code>SELECT to_regclass('&lt;approved-schema&gt;.&lt;approved-write-probe&gt;') IS NULL AS safe_to_test;&#10;BEGIN READ ONLY;&#10;CREATE TABLE &lt;approved-schema&gt;.&lt;approved-write-probe&gt; (probe_id integer);&#10;ROLLBACK;&#10;SELECT to_regclass('&lt;approved-schema&gt;.&lt;approved-write-probe&gt;') IS NULL AS probe_absent;</code></pre><div class="success-criteria"><h3>Success criteria</h3><ul><li>MagicDNS works and <code>verify-full</code> remains enabled.</li><li>SCRAM and, where supported, channel binding succeed.</li><li><code>current_database()</code>, <code>current_user</code>, and read-only state are correct.</li><li><code>pg_stat_ssl</code> confirms SSL.</li><li>Only approved schema USAGE and table SELECT are true.</li><li>CREATE, INSERT, UPDATE, DELETE, and TRUNCATE are false.</li><li>The write attempt fails and <code>probe_absent</code> is true.</li></ul></div></section>
