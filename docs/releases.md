# Releases and compatibility

| Category | Component | Current public release | Current role |
| --- | --- | --- | --- |
| Framework | Governed Research Workspace Framework | [v0.4.0](https://github.com/chenhaoran2068/governed-research-workspace-framework/releases/tag/v0.4.0) | Optional managed-local reference-library boundary. |
| System | Governed Research Workflow | [v1.12.0](https://github.com/chenhaoran2068/governed-research-workflow/releases/tag/v1.12.0) | Optional metadata-only Study handoff. |
| Skill | research-paper-reading | [v0.2.0](https://github.com/chenhaoran2068/research-paper-reading/releases/tag/v0.2.0) | Paper reading and optional managed knowledge service. |
| Skill | research-ethics | [v1.1.1](https://github.com/chenhaoran2068/research-ethics/releases/tag/v1.1.1) | Independent ethics-preparation capability. |

These Releases are published and installed independently. The portal provides navigation only; it cannot publish, install, enable, or authorize a component.

The managed knowledge service is optional. Without it, the reading Skill remains `session_only`, and the Research System does not try to read papers or notes.
