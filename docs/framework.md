# Governed Research Workspace Framework

## 它是什么

工作区 Framework 定义通用的工作区根目录、System 注册、项目绑定和多 System 隔离边界。

## 解决什么问题

它让一个工作区能明确哪个 System 对一个项目负责，并避免把项目内部规则错误提升为所有 System 的通用要求。

## 不做什么

它不规定每个研究项目必须采用同一分析目录、代码语言、手稿结构或伦理流程，也不保存真实研究材料。

## 何时进入

建立、扩展或审核工作区结构、System 注册、项目绑定和根目录退役时进入。

## 与其他组件的关系

Research Workflow 使用 Framework 的绑定概念，但拥有研究项目内部的生命周期、执行和手稿规则。伦理模块不改变 Framework 的根目录合同。
