# Frameworks

## Governed Research Workspace Framework

**Current public release:** [v0.4.0](https://github.com/chenhaoran2068/governed-research-workspace-framework/releases/tag/v0.4.0)

This Framework defines workspace ownership, System registration, public/private boundaries, and multi-System isolation. It does not prescribe a Study's design, analysis, manuscript, or ethics decision.

### Optional knowledge-service boundary

Version 0.4.0 adds a generic, opt-in boundary for a managed local reference library. The Framework defines service ownership and isolation, but does not read papers, import PDFs, create notes, or replace any reading tool.

The reading Skill can configure and use that service only after an explicit user request and source-specific confirmation.
