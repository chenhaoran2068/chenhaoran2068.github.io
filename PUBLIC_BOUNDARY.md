# Public Boundary

This portal is a public explanation and navigation layer. It contains only
original public-facing text, diagrams, reviewed release identities, and links
to formal public sources.

It must not contain private paths, local runtime information, Study materials,
data, people, internal decisions, source identifiers, evaluation evidence, or
private experience records. A component page may describe a boundary, but the
component's tagged public repository remains the formal source of authority.

The portal does not automatically synchronize from component repositories.
Each update requires a human review of the cited public release and links.
