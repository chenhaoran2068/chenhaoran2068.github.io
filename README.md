# Chenhaoran Governed Research Collaboration

This repository contains a public navigation portal for the maintained
research collaboration components published by \`chenhaoran2068\`.

It explains component boundaries, user entry paths, current reviewed releases,
and links to the formal sources of authority. It does not replace those
sources, publish private working materials, or grant any research, governance,
or release authority.

The site is built with MkDocs and is intended for GitHub Pages deployment.
